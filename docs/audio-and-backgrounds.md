# 背景、声音与专注音频

本页说明 MathCoach 的外观与声音边界。所有音频默认关闭，所有背景默认无背景。

## 背景

- 默认：无背景。
- 可选：纸张纹理、点阵网格、对角细线，均改编自 Pattern Craft（MIT）。
- 仅使用常量 CSS，不加载外部图片，不拼接用户输入。
- 按实际生效的 Streamlit 浅色/深色主题选择对应变体；主题变更仍需重启应用。
- 背景为静态图案，无动画，不依赖 `prefers-reduced-motion` 的动画分支。
- 在“设置 → 外观”中切换；选择“无背景”时不注入任何背景 CSS。

## 答题反馈音

- 默认关闭。总开关为“启用声音”，另有“答题反馈音”开关。
- 使用 uisfx 的 organic 包 4 个 cue：正确、错误、完成、点击。音频为 CC0 1.0。
- 音频以 base64 常量嵌入代码，不依赖静态文件服务或网络；不新增二进制资源。
- 仅在用户提交答案或完成闭环等操作后播放；进入应用时不自动播放。
- 浏览器可能拦截自动播放。设置页提供原生播放器试听；若反馈音未响，可在试听播放器中确认浏览器音量与自动播放策略。
- 应用内没有音量滑块；音量由浏览器原生播放器/系统音量控制。这是当前 Streamlit 原生音频能力的限制。
- 对错与完成状态始终有视觉反馈，声音不是唯一信息通道。

## 专注音频

- 默认关闭，仅提供外部入口，不内置曲库。
- 入口：Noisekun、Moodist、Open Lo-Fi。点击链接会在浏览器中打开对应网站。
- 本应用不播放、不暂停、不调节外部页面的音频，也无法在其关闭后停止外部标签页中的播放；请在对应网站控制播放与音量。
- 外部曲库的许可证与使用条款由对应项目负责，本应用仅提供入口。
- 不打包大曲库，不依赖网络，除非用户主动打开外部链接。

## 浏览器自动播放限制

`st.audio` 与 HTML5 audio 都受浏览器自动播放策略约束：用户未与页面交互前，浏览器通常不会自动播放未静音音频。因此：

- 首次进入不会播放声音。
- 开启声音后，反馈音依赖此前的用户点击；部分浏览器仍可能拦截。
- 设置页的“试听”按钮是显式的用户手势，适合确认浏览器音量与输出设备。
- 专注音频不尝试自动播放；它只是外部链接。

## 无障碍

- 背景静态、低对比度，不遮挡正文。
- 声音默认关闭，可随时关闭。
- 正确/错误/完成状态不依赖声音传递。
- 专注音频为外部入口，不阻塞主流程。
