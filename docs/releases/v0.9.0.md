# MathCoach v0.9.0

发布日期：2026-11-28

## 亮点

- 新增教学链路：KC 目录、教案/出题 Gate，以及 L3/L4 两级追问；试点范围为单一 KC `kc-hs-trig-002-f1`。
- 分步错误定位覆盖 hs-trig 全部 15 道题，共 29 个步骤；步骤级 KC 掌握度写入独立影子库，不修改正式 BKT。
- 草稿行为信号记录步骤耗时、缺失与放弃，并只用于调整 KC 影子观测质量。
- 新增智能练习册：按薄弱 KC、到期复习与迁移题配额选题，可导出 Markdown/HTML。
- 新增可解释学情报告：结论—证据结构 + 可选受限 AI 叙事，失败时回退确定性模板。
- 新增相似题召回、错题变式与可打印练习单。
- 新增 KC 前置依赖图与只读修复建议：仪表盘优先推荐先修卡，不改 FSRS 队列。
- 新增 KC 动态可视化讲解：象限符号判定、补角公式、振幅与周期。
- 交互延迟优化：周报叙事按需生成、仪表盘/周报单次快照、KC 批量缓存、小测表单与片段化渲染。

## 修复

- 步骤判定兼容上标、乘除号、负号与 NFKC 归一化。
- KC 影子库不存在时不再创建空库；数据缺失时展示与推荐自动回退。
- 周报叙事在无结论、模型不可用或输出不合规时保留确定性报告。
- 切换卡片、重置或重开时自动放弃未结算的步骤运行。

## 验证

- `MATHCOACH_CONTENT_STRICT=1 python -m pytest -q`：816 passed，5 skipped。
- 新增 AppTest 覆盖分步填写与放弃、周报叙事按需生成、前置修复 UI、KC 动态讲解入口与降级。

## 安装

- Windows x64：`MathCoachSetup-0.9.0.exe` 或 `MathCoach-windows.zip`
- macOS：`MathCoach-0.9.0.dmg` 或 `MathCoach-macos.zip`
- 资产由 GitHub Release 发布后构建并上传，详见 `docs/install.md`。
