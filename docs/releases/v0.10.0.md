# MathCoach v0.10.0

发布日期：2026-11-28

## 亮点

- REMSJ 元认知支架（小切片）：提示页按 L1–L6 映射复述题意、提取条件、关联概念、求解与说明理由；步骤判定新增步骤级错因映射。
- 草稿原位标注：已判定步骤改为行内卡片，展示输入、判定徽标与可展开原因；错误步骤给出步骤级错因与 KC 动态讲解，不展示标准答案。
- 情境化仿真入口：新增切点斜率与向量合成两个参数可调情境，提供观察提示与做题衔接；情境探索不计入掌握度。
- 分步板书：为振幅周期与余弦定理配置 8 个步骤帧，含图形状态、文字说明与追问锚点；帧内数学声明先过 verify。
- 余弦定理动态讲解：新增 `kc-hs-trig-005-f1` 三角形图。
- 语音追问输入（可选）：本地 Whisper 转写 + 数学口语规范化；未安装、失败或空结果回退文字输入。
- 行为信号驱动的表示降级：连续错误、追问未命中、提示请求、耗时异常等信号达到门槛时，提示讲解降为具体例子；事件写入独立信号库并回填下一次作答结果。

## 边界

- 未修改 `verify/`、BKT、FSRS、主线判分与收据独立性。
- 语音依赖 `faster-whisper` 为可选依赖，未安装时隐藏语音入口。
- 情境探索与表示降级事件均不写入正式学习档案。

## 验证

- `MATHCOACH_CONTENT_STRICT=1 python -m pytest -q`：900 passed，5 skipped。
- 新增 AppTest 覆盖：表示降级、分步板书、余弦图、向量图、语音规范化、草稿原位标注、REMSJ 阶段、情境参数。

## 安装

- Windows x64：`MathCoachSetup-0.10.0.exe` 或 `MathCoach-windows.zip`
- macOS：`MathCoach-0.10.0.dmg` 或 `MathCoach-macos.zip`
- 资产由 GitHub Release 发布后构建并上传，详见 `docs/install.md`。
