# MathCoach v0.8.0

发布日期：2026-11-27

## 亮点

- 诊断后可直接去复习先修卡、看学习卡片，或练同卡其他题组成的小复习包。
- 收据页支持 L6 费曼复述：按标准思路的关键片段覆盖率记录质量，待补充时回流一次半独立复习。
- 推荐与掌握度打通：下一步推荐按 BKT 掌握度排序，并可用“推荐开始”直接进入陪练。
- 周报新增掌握度变化：掌握度更新会留下历史快照，周报对比本周基准与最新值。

## 修复

- 提示后答对不再被 FSRS 记为 `AGAIN`，稳定性不再被误重置；SM-2 模式下同样按提示档位计算间隔。
- 复习登记与诊断确认不再重复推进 BKT 掌握概率。
- 提示后答对在 BKT 中只按一半学习增益计入，避免掌握度虚高。
- “今天到期 / 今日待复习”只统计当天结束前到期的条目。
- 三维可视化的竖直平面不再画在 z=0。
- Windows 上符号验证子进程不再重跑整页，`expr` 题可正常自动核对。

## 验证

- `MATHCOACH_CONTENT_STRICT=1 python -m pytest -q`：553 passed，5 skipped。
- 新增端到端 AppTest：讲解 → 小测 → 收据 → L6 复述 → 结算 → 仪表盘 → 周报 → 重启持久化。
- 本地启动 Streamlit 首页返回 HTTP 200。

## 安装

- Windows x64：`MathCoachSetup-0.8.0.exe` 或 `MathCoach-windows.zip`
- macOS：`MathCoach-0.8.0.dmg` 或 `MathCoach-macos.zip`
- 资产由 GitHub Release 发布后提供，详见 `docs/install.md`。
