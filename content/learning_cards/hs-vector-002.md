# 向量的加减法

> 知识点 ID：hs-vector-002
> 所属：高中 · 平面向量 · 向量运算
> 状态：已填充（来源：现有卡片内容）

## 概念

若 a=(x1,y1)，b=(x2,y2)，则 a±b=(x1±x2,y1±y2)，ka=(kx1,ky1)。

## 直觉

坐标运算就是对应分量分别相加减。

## 常见误区

- 加减法时分量的顺序写错
- 数乘只乘一个分量

## 诊断例题

**题目**：(1,2)+(3,4)=（ ）

**选项**：(4,6) / (3,6) / (4,2) / (2,2)

**答案**：(4,6)

**思路**：对应分量相加。
