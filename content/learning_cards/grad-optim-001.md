# 凸集与凸函数

> 知识点 ID：grad-optim-001
> 所属：研究生 · 最优化方法 · 凸性
> 状态：已填充（来源：现有卡片内容）

## 概念

凸集满足 (1−t)x+ty∈C；凸函数满足 f((1−t)x+ty)≤(1−t)f(x)+tf(y)。

## 直觉

凸集的任意两点连线仍在集合内，凸函数图像在弦下方。

## 常见误区

- 把凸函数图像方向记反
- 忽略定义域凸性

## 诊断例题

**题目**：集合 C 为凸集的条件是（ ）

**选项**：任意两点连线仍在 C 内 / 任意两点距离小于 1 / C 有界 / C 包含原点

**答案**：任意两点连线仍在 C 内

**思路**：凸集的定义。
