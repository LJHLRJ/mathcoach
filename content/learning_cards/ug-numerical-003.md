# 牛顿迭代法

> 知识点 ID：ug-numerical-003
> 所属：本科 · 数值分析基础 · 方程求根
> 状态：已填充（来源：现有卡片内容）

## 概念

x_{n+1}=x_n−f(x_n)/f′(x_n)，在单根附近通常二次收敛。

## 直觉

用切线逼近曲线，切线与 x 轴的交点作为下一个近似。

## 常见误区

- 导数为 0 时仍迭代
- 忽略初值选择

## 诊断例题

**题目**：牛顿迭代公式是（ ）

**选项**：x_{n+1}=x_n−f/f′ / x_{n+1}=x_n+f/f′ / x_{n+1}=f/f′ / x_{n+1}=x_n/2

**答案**：x_{n+1}=x_n−f/f′

**思路**：由切线方程与 x 轴交点得到。
