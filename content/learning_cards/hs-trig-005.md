# 解三角形

> 知识点 ID：hs-trig-005
> 所属：高中 · 三角函数 · 解三角形
> 状态：已填充（来源：现有卡片内容）

## 概念

正弦定理 a/sin A=b/sin B=c/sin C；余弦定理 c²=a²+b²−2ab cos C。

## 直觉

已知边角关系时，正弦定理管“对边对角”，余弦定理管“三边一角”。

## 常见误区

- 正弦定理中边角不对应
- 余弦定理漏掉负号

## 诊断例题

**题目**：余弦定理的正确形式是（ ）

**选项**：c²=a²+b²−2ab cos C / c²=a²+b²+2ab cos C / c²=a²−b²+2ab cos C / c²=a²+b²−ab cos C

**答案**：c²=a²+b²−2ab cos C

**思路**：两边平方展开后得到余弦定理。
