# 充分必要条件

> 知识点 ID：hs-set-003
> 所属：高中 · 集合与逻辑 · 常用逻辑用语
> 状态：已填充（来源：现有卡片内容）

## 概念

若 p⇒q，则 p 是 q 的充分条件，q 是 p 的必要条件；若 p⇔q，则 p 与 q 互为充要条件。

## 直觉

充分条件保证结论发生，必要条件是被结论逼出来的条件。

## 常见误区

- 把充分条件和必要条件说反
- 用特例代替一般证明

## 诊断例题

**题目**：“x>0”是“x²>0”的（ ）

**选项**：充分不必要条件 / 必要不充分条件 / 充要条件 / 既不充分也不必要条件

**答案**：充分不必要条件

**思路**：x>0 一定能推出 x²>0，但 x²>0 还可能 x<0。
