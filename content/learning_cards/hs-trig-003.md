# 诱导公式

> 知识点 ID：hs-trig-003
> 所属：高中 · 三角函数 · 三角恒等变换
> 状态：已填充（来源：现有卡片内容）

## 概念

sin(π−x)=sin x，cos(π−x)=−cos x；sin(π+x)=−sin x，cos(π+x)=−cos x。

## 直觉

诱导公式把大角、负角化到熟悉的锐角。

## 常见误区

- 只记符号不记函数名
- 把 cos(π+x) 的符号写反

## 诊断例题

**题目**：sin(π−x) 等于（ ）

**选项**：sin x / −sin x / cos x / −cos x

**答案**：sin x

**思路**：利用“补角正弦相等”。
