# 集合的运算

> 知识点 ID：hs-set-002
> 所属：高中 · 集合与逻辑 · 集合
> 状态：已填充（来源：现有卡片内容）

## 概念

A∩B={x | x∈A 且 x∈B}；A∪B={x | x∈A 或 x∈B}；A\B 表示属于 A 但不属于 B 的元素。

## 直觉

交集找“共同部分”，并集把两边合起来。

## 常见误区

- 把并集当成交集
- 求补集时忽略全集

## 诊断例题

**题目**：已知 A={1,2}，B={2,3}，则 A∩B=（ ）

**选项**：{1} / {2} / {3} / {1,2,3}

**答案**：{2}

**思路**：同时属于 A 和 B 的元素只有 2。
