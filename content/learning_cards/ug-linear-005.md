# 特征值与特征向量

> 知识点 ID：ug-linear-005
> 所属：本科 · 线性代数 · 特征值
> 状态：已填充（来源：现有卡片内容）

## 概念

若 Ax=λx（x≠0），则 λ 为特征值，x 为特征向量；λ 由 |A−λI|=0 求出。

## 直觉

特征向量是被矩阵作用后方向不变的向量，特征值是伸缩倍数。

## 常见误区

- 忘记特征向量非零
- 把特征值当成矩阵元素

## 诊断例题

**题目**：矩阵 [[2,0],[0,3]] 的特征值是（ ）

**选项**：2 和 3 / 0 和 0 / 1 和 1 / 2 和 −3

**答案**：2 和 3

**思路**：对角矩阵的特征值就是对角元。
