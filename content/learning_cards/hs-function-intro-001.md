# 函数的概念

> 知识点 ID：hs-function-intro-001
> 所属：高中 · 函数与导数 · 函数概念
> 状态：已填充（来源：现有卡片内容）

## 概念

设 A、B 是非空数集，若按某个对应关系 f，对 A 中任意 x，B 中都有唯一确定的 y 与之对应，则称 f 为从 A 到 B 的函数。

## 直觉

函数像一台“输入一个数、吐出一个数”的机器，同一个输入只能得到唯一输出。

## 常见误区

- 把“一个 x 对应两个 y”的关系当成函数
- 只看解析式，忽略定义域限制

## 诊断例题

**题目**：下列对应关系中，y 是 x 的函数的是（ ）

**答案**：y = x²

**思路**：每个 x 只有唯一 y 与之对应；其余关系会出现一个 x 对应两个 y。
