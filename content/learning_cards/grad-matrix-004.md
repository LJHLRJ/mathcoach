# 特征值与对角化

> 知识点 ID：grad-matrix-004
> 所属：研究生 · 矩阵论 · 特征值
> 状态：已填充（来源：现有卡片内容）

## 概念

n 阶矩阵 A 可对角化当且仅当它有 n 个线性无关的特征向量。

## 直觉

对角化就是找到一组特征向量基，使矩阵变成对角形。

## 常见误区

- 以为有重特征值就不能对角化
- 忽略特征向量个数

## 诊断例题

**题目**：n 阶矩阵 A 可对角化的充要条件是（ ）

**选项**：有 n 个线性无关的特征向量 / 特征值互不相同 / A 对称 / det A≠0

**答案**：有 n 个线性无关的特征向量

**思路**：特征向量构成可逆矩阵即可对角化。
